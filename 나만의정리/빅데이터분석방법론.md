# 빅데이터 분석 방법론

전체 흐름
1. 분석기획
2. 데이터 준비
3. 데이터 분석
4. 시스템 구현
5. 평가 및 전개

> 기준분구평
> 1. 회원 이탈예측 프로젝트를 하겠습니다  
> 2. 고객정보하고 접속로그 주세요  
> 3. 결측치 처리 → 분포 확인 → 분석
> 4. 웹서비스에 완성된 모델을 넣겠습니다
> 5. 정확도 85% 나왔습니다. 실제 업무에 사용 가능합니다.

# KDD, CRISP-DM과의 구분

| 방법론 | 한마디로 | 시작 | 끝 | 단계암기 |
| ---- | ----- | ---- | ---- | ------- |
| 빅데이터 분석 방법론 | 분석 프로젝트 전체를 수행 | 프로젝트 기획 | 시스템 적용/평가 | 기→준→분→구→평 |
| KDD | 데이터에서 지식을 캐냄 | 데이터 선택 | 발견한 지식 해석 | 선→전→변→마→평 |
| CRISP-DM | 비즈니스 문제를 데이터마이닝으로 해결 | 업무 이해 | 현업 전개 | 업→데→데이터→모델→평가→전 |

- KDD : 데이터가 주인공 (데이터 → 지식)
- CRISP-DM : 회사가 주인공 (회사의 문제해결을 위해 데이터를 이용)
- 빅데이터 분석 방법론 : 프로젝트가 주인
