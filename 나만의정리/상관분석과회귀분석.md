# 상관분석과 회귀분석

- 상관분석 : `X`가 변하면 `Y`도 변하는가?
- 회귀분석 : `X`가 바뀌면 `Y`가 얼마나 바뀌는가?

## 사례 : 공부시간과 시험점수 분석

- 상관분석 : 공부시간이 많으면 시험점수도 높은가?
- 회귀분석 : 1시간 공부하면 몇 점 정도 오르는가?

## 그 외의 사례들

| 항목 | 분석방법 |
| --- | --- |
| 키가 크면 몸무게가 많이 나가는가? | 상관분석 |
| 키가 1cm 증가하면 몸무게는 얼마나 늘어나는가? | 회귀분석 |
| 광고비를 많이 쓰면 매출이 늘어나나? | 상관분석 |
| 광고비를 100만원 늘리면 매출이 얼마나 변할까? | 회귀분석 |
| 운동량이 줄어들면 체중이 늘어나는가? | 상관분석 |
| 운동량의 변화에 따른 체중량 예측 | 회귀분석 |

# 구분을 위한 추가 힌트

- 상관분석 : `X`와 `Y`를 대등한 관계로 봄
- 회귀분석 : `X`를 독립변수, 설명변수로 보고 `Y`를 종속변수, 반응변수로 봄

# 주의

- 상관관계는 인과관계가 아니다 
    - 아이스크림 판매량과 익사 사고가 양의 상관관계를 보이더라도 인과관계는 아니다.
    - 둘 사이에는 기온이라는 숨겨진 제 3의 변수가 존재하기 때문
- 회귀분석도 인과관계를 증명하지는 않는다



# 회귀분석 좀 더 알아보기

회귀분석은 종속변수인 `Y`가 어떤 형태냐에 따라 구분하는 것이 쉽다

| 상황 | 종류 |
| ---- | ---- |
| Y가 연속형 숫자 | 선형회귀 |
| Y과 0/1같은 이진 범주 | 로지스틱회귀 |
| X가 하나 | 단순회귀 |
| X가 여러개 | 다중회귀 |
| 변수는 많지만 과적합/다중공선성 걱정 | Ridge(L1) / Lasso(L2) / Elastic Net |
| Y가 개수(count) | Poisson 회귀 |

### 1. 단순 선형 회귀

독립변수 `X`가 1개, 종속변수 `Y`가 연속형일 때 사용
- 공부시간(X) → 시험점수(Y)
- 광고비(X) → 매출(Y)
- 면적(X) → 집값(Y)

### 2. 다중 선형 회귀

- 면적(X₁) + 역과의거리(X₂) + 방개수(X₃) + 건축연도(X₄) → 집값(Y)

<div style="color:red">
추가될 수 있는 항목들 : 
- 다중공선성
- VIF(분산팽창계수)
- 결정계수 R²
- 수정된 결정계수 Adjusted R²
</div>

> ### 결정계수(R²)  
> 종속변수의 변동 중에서 회귀모델이 설명하는 비율  
> `R² = 0.80` 이면 종속변수 변동의 약 `80%`를 이 회귀모델이 설명한다는 의미  
> <span style="color:red">쓸데없는 변수를 추가해도 거의 내려가지 않음</span>
> 공식 : R² = SSR/SST = 1 - (SSE/SST)  
> - SST : 전체 변동  
> - SSR : 회귀모형이 설명한 변동  
> - SSE : 회귀모형이 설명하지 못한 변동 (오차)  

> ### 수정된 결정계수 (Adjusted R²)
> 변수를 추가했을 때 그 변수가 실제로 설명력 향상에 기여하지 못하면 페널티를 부여  
> 공식 : Adjusted R² = 1 - (1-R²) * (n-1) / (n-p-1)  
> - n : 관측개수  
> - p : 독립변수 개수 (항 개수)  

### 3. 로지스틱 회귀

이름은 회귀이지만 `분류`를 목표로 하는 기법

> 공부시간, 출석률, 과제점수를 통해 이 학생의 합격/불합격 여부를 예측하고 싶다

확률을 구해야 하기 때문에 시그모이드 함수를 통과시켜 모든 값을 확률로 변경

p = 1 / (1 + e^-z)

> 분류임에도 회귀라는 이름을 쓰는 이유는 직접 판정을 해주는게 아니라 판정을 위한 선형식을 모델링하기 때문이다. 
> 
> Odds = p / (1 - p)
> 
> 합격확률이 `80%`라면 `0.8 / 0.2`이므로 합격할 가능성이 불합격할 가능성보다 4배의 odds를 가진다고 말할 수 있다

#### odds와 odds ratio

- odds : 집단 내에서 `일어남 vs 안일어남`을 비교
- odds ratio : 두 집단의 odds를 서로 비교
