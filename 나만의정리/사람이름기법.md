# 사람이름으로 된 분석기법들

- 상관관계 : Pearson, Spearman, Kendall
- 정규성 : Shapiro-Wilk, Kolomogorov-Smirnov, Anderson-Darling, Jarque-Bera
- 등분산성 : Bartlett, Levene
- 비모수 : Mann-Whitney U , Wilcoxon signed-rank, Kruskal-Wallis, Friedman


# 상관관계 분석

| 방법 | 데이터/조건 | 측정항목 | 핵심 |
| --- | ----------- | -------- | ---- | 
| Pearson | 연속형, 선형관계 | 선형 상관 | 값 자체 |
| Spearman | 서열/비정규 | 단조 상관 | 순위 |
| Kendall | 서열형, 작은 표본 | 순위 일치 정도 | 쌍의 일치 |


상관관계를 분석하는 이유는 두 변수의 값이 함께 움직이는 경향이 있는지를 확인하기 위해서이다. 예를들어 쇼핑몰에서 고객의 구매금액이 방문횟수, 체류시간, 장바구니 상품수, 할인율 중 어떤것과 가장 관련이 있는지를 찾아서 그에 맞는 의사결정을 하는 등의 목적에 의해 시행한다.

상관계수(`r`)는 일반적으로 `-1 ≤ r ≤ 1`의 관계를 가진다.

양의 상관관계일 수록 `1`에 가까워지며, 음의 상관관계일수록 `-1`에 가까워진다. **산점도**를 통해 이를 확인하는 것이 직관적이다.

상관관계는 문제의 원인 후보군을 찾는데 매우 유용하다.

- 피어슨은 키와 몸무게의 관계 등 연속형 변수
- 스피어만은 성적등수와 공부시간 등 순위나 단조관계를 봄

<span style="color:red">상관관계는 함께 움직인다는 것을 보여줄 뿐, 다른 한 쪽의 원인이라는 것을 증명하지 않는다.</span>

# 다중공선성(multicollinearity)

독립변수간에 지나친 상관관계가 존재하는 경우 (ex : 전용면적과 평수)

다중공선성이 있으면 제거하는것이 좋으며, 기준이 되는 값은 변수를 제거하거나 결합, PCA, L1/L2 규제를 이용하는 방법 등이 있다.

다중공선성이 있는지 판단하기 위해서 사용하는 값이 VIF(분산팽창계수)이며 일반적으로 다음과 같이 해석한다.

| VIF | 해석 |
| ---: | :--- |
| 1 | 다중공선성 거의 없음 |
| 1 ~ 5 | 일반적으로 큰 문제 없음 |
| 5 이상 | 다중공선성 의심됨 |
| 10 이상 | 심각한 다중공선성이 의심됨 |

> VIF = 1 / (1 - R²)

# 사람 이름이 들어가지 않은 상관관계 분석기법

- 공분산(Covariance)
- 자기상관(Autocorrelation)
- 편상관(Partial Correlation)
- 교차상관(Cross-correlation)
- 점이연 상관(Point-biserial)
- 파이 계수
- 상관비

## 공분산

두 변수가 같은 방향으로 움직이는지 반대 방향으로 움직이는지 볼 때 사용

- `공분산 > 0` → 같은 방향으로 움직인다
- `공분산 < 0` → 반대 방향으로 움직인다
- `공분산 = 0` → 같이 움직이는 경향이 약함

공분산은 방향만 알 수 있을 뿐 단위에 따라 수치가 달라질 수 있기 때문에 공분산을 `-1 ~ 1` 범위로 만든 것이 일반적인 상관계수라고 보면 된다.

## 편상관

제 3의 변수 영향을 제거하고 관계를 따져 분석하는 기법.

B → A, C 일 때 A에서 B의 영향을 제거한 잔차와 C에서 B의 영향을 제거한 잔차를 비교

## 자기상관

주가, 월별 매출, 기온, 경제지표, 사이트 방문자 수 등 **시간 흐름에 따라 연속성이 있는 데이터**에서 발생하는 상관관계

- 양의 상관관계 : 값의 변화가 일정한 경우 (증가 or 감소)
- 음의 상관관계 : 값의 변화가 들쭉날쭉한 경우
- 이전 값이 다음 값을 설명하지 못한다면 `0`이라고 봄 (ex : 백색잡음)

보통 오차는 독립적이라고 본다 (어제의 오차가 오늘의 오차에 영향을 미치지 않는다)

잔차들의 1차 자기상관을 확인하기 위한 대표적인 통계량으로 `Durbin-Watson 통계량`이 존재한다.

> 범위 : 0 ≤ DW ≤ 4

| DW | 해석 |
| --: | :-- |
| 약 2 | 자기상관 없음 |
| 2보다 작음 | 양의 자기상관 가능 |
| 2보다 큼 | 음의 자기상관 가능 |
| 0 근처 | 강한 양의 자기상관 | 
| 4 근처 | 강한 음의 자기상관 |

## 자기상관과 정상성

- 자기상관 : 과거와 현재가 관계있는가?
- 정상성 : 시간에 따라 평균/분산/통계적 특성이 안정적인가?

## 일반상관과 자기상관

- 일반상관 : 다른 변수
- 자기상관 : 같은 변수(다른 시점)

# 카이제곱 

범주형 데이터에서 서로 관계가 있는지 파악하기 위한 검정

> 100명(남50,여50)을 조사했을 때   
> 남 - A상품(40), B상품(10)  
> 여 - A상품(15), B상품(35)  
> 와 같은 구매패턴을 보일 때 *성별과 상품 선호도가 실제 관련이 있는지* 검정하기 위한 기법

100명 중 55명이 A상품을 구매했으므로 만약 성별에 따른 상품 선호가 전혀 관계없다면 남성 중에서도 `50 x 0.55 = 27.5`명은 A상품을 구매해야 한다. 실제로 남성 중 A상품을 구매한 사람은 `40명`이므로 차이가 크다고 볼 수 있다. 이러한 정보를 모든 칸에서 조사해서 종합한것이 카이제곱(x²) 검정통계량이다.

> x² = Σ(실제값-기대값)²/기대값
> df = (행-1) * (열-1)

위 두 개를 가지고 카이제곱분포표에서 값을 찾아서 통계적 유의여부를 판정한다 (문제에서 주어짐)

# 정규성 검정

정규성 검정은 **이 데이터가 정규분포를 따른다고 볼 수 있는지 여부를 확인**하는 검정이다.

많은 통계기법들이 데이터 또는 오차가 정규분포를 따른다는 가정을 전제로 사용하기 때문에 정규분포를 만족하느냐를 먼저 검정하고, 심하게 만족하지 않을 경우는 다른 방법을 사용하는 쪽으로 결정할 수 있다.

> 귀무가설(H0) : 데이터가 정규분포를 따른다  
> 대립가설(H1) : 데이터가 정규분포를 따르지 않는다  
> p-value가 `0.05` 미만이면 귀무가설 기각, 대립가설 채택

## 샤피로-윌크(Shapiro-Wilk) 검정

실제 데이터의 정렬된 모양이 정규분포에서 기대되는 모양과 얼마나 비슷한지를 검정

- W : 1에 가까울수록 정규분포와 비슷 (참고만)
- p : 가설검정에 대한 결과

## Kolmogorov-Smirnov 검정 (KS검정)

실제 데이터의 누적분포(CDF)와 기준 분포의 누적분포가 얼마나 다른지 비교하는 검정방법

`Shapiro-Wilk`와의 차이는 정규성을 검정하는 것이 목적이 아니라 **서로 다른 두 분포의 일치 여부**를 검정한다는것

<span style="color:red">서로 다른 두 분포의 가장 큰 차이가 발생하는 지점을 중요하게 다룸</span>

## Anderson-Darling 검정

이 검정은 데이터가 특정 확률분포를 따르는지 확인하는 적합도 검정이다. 정규성 검정에 자주 쓰이고 KS 검정보다 분포의 **꼬리 부분에 더 민감**한 것이 핵심이다.

<span style="color:red">양쪽 꼬리의 분포차이에 큰 가중치를 두고 비교하는 방식</span>

# 등분산성 검사

모수검정의 형태 중 집단 간 분산이 동일하다는 가정을 사용하는 경우가 많기 때문에 정규성 검정 다음에는 등분산성 검정 순으로 진행됨

- F-test
- Bartlett
- Levene
- Brown-Forsythe

## F검정

두 집단의 분산을 무식하게 비교

> `F` 통계량이 `1`에 가까울수록 분산이 비슷함

## Bartlett 검정

여러 집단의 분산이 같은지를 검정하기 위한 방법

p값이 `0.05` 이상이면 등분산성을 만족한다고 보고, 작으면 등분산성을 만족하지 않는다고 본다 (귀무가설 기각, 대립가설 채택)

<span style="color:red">정규성이 충분히 확보되었고, 이상치가 없는 경우에만 제대로된 결과가 나올 가능성이 높다</span>

## Levene 검정 ★★★

등분산성 검정의 대표적인 형태  

여러 집단의 분산이 동일한지 검정할 때 사용

제곱을 사용하여 이상치에 민감한 F검정, Bartlett 검정과 다르게 **각 관측값에 대한 중심으로부터의 거리**를 이용하여 비교하는 방식이므로 상대적으로 강건한 모습을 보인다.

## Brown-Forsythe 검정

Levene의 변형된 방식의 검정

중심을 평균으로 잡는 Levene와 다르게 중앙값(Median)을 중심으로 잡기 때문에 이상치 또는 비대칭 분포에 Levene보다 더 강건할 수 있음.

# 평균 차이 검정

정규성 검증과 등분산성 검증 결과에 따라 다양한 검증방법을 사용하여 서로 다른 두 집단간의 유의미한 차이가 있는지를 검증할 수 있다.

- 집단이 독립적인 경우
  - 비교집단이 두 개인 경우
    - 정규성 만족
      - 등분산성 만족 : `Student t-test`
      - 등분산성 불만족 : `Welch t-test`
    - 정규성 불만족 : `Mann-Whitney U 검정`
  - 비교집단이 세 개 이상인 경우
    - 정규성 만족
      - 등분산성 만족 : `일원배치 ANOVA`
      - 등분산성 불만족 : `Welch ANOVA`
    - 정규성 불만족 : `Kruskal-Wallis 검정`
- 집단이 대응적인 경우
  - 비교집단이 두 개인 경우
    - 정규성 만족 : `대응표본 t-test`
    - 정규성 불만족 : `Wilcoxon signed-rank`
  - 비교집단이 세 개 이상인 경우
    - 정규성 만족 : `반복측정 ANOVA`
    - 정규성 불만족 : `Friedman`
