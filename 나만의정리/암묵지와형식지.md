# 지식경영의 핵심 이슈인 암묵지와 형식지
- 암묵지 - 학습, 체험을 통해 개인이 습득한 무형의 지식
- 형식지 - 메뉴얼화 된 유형의 지식

# 이들을 구분하는 이유
결국 업무라는건 개인이 체득한 것들을 메뉴얼로 만들고, 이걸 습득해서 메뉴얼로 표현하기 어려운 실전 경험을 쌓는 과정의 반복이기 때문이다.
- 내면화(Internalization) : 현장 경험으로 축적된 지식
- 공통화(Socialization) : 개인의 지식을 공유하여 조직의 지식으로 만드는 과정
- 표출화(Externalization) : 메뉴얼 작성을 통해 암묵지를 정형화된 형식으로 표출하는 과정
- 연결화(Combination) : 표출화된 지식을 학습하면서 본인의 경험과 접목시키는 과정
