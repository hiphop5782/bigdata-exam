# 모델의 종류와 특징

모델은 다음과 같은 대분류를 가진다.

```
머신러닝
├─ 1. 지도학습 (Supervised Learning)
│    ├─ 회귀
│    └─ 분류
│
├─ 2. 비지도학습 (Unsupervised Learning)
│    ├─ 군집
│    ├─ 차원축소
│    └─ 연관규칙
│
├─ 3. 준지도학습 (Semi-Supervised Learning)
│
├─ 4. 강화학습 (Reinforcement Learning)
└─ 5. 자기지도학습 (Self-Supervised Lerning)
```

1. 지도학습 - 정답(Label)이 있는 데이터로 학습
2. 비지도학습 - 정답(Label)이 없는 데이터로 학습
3. 준지도학습 - 정답이 있는 데이터 일부와 정답이 없는 데이터로 학습
4. 강화학습 - 정답에 가까운 행동을 했을 때 보상을 받는 방식의 학습
5. 자기지도학습 - 데이터 자체에서 정답을 만들어서 학습하는 방식 (LLM,대규모 사전학습)

<span style="color:red">정답(Label)의 유무로 구분</span>


# 지도 학습

정답이 있는 데이터로 학습하는 방식

1. 회귀(Regression) - 정답이 연속적인 숫자
2. 분류(Classification) - 정답이 범주/클래스

### 회귀(Regression)

결과가 숫자일 때 사용

- 공부시간 → 시험점수
- 광고비 → 매출액
- 면적 → 집값
- 기온 → 전력사용량

### 분류(Classfication)

결과가 종류, 범주, 클래스일 때 사용

- 메일 → 스팸/정상
- 환자 → 질병/정상
- 고객 → 이탈/유지
- 사진 → 고양이/강아지
- 신용 → 우량/보통/불량

| 모델 | 특징 |
| --- | --- |
| 로지스틱 회귀 | 확률 기반의 분류 |
| 의사결정나무 | 규칙 기반이며 해석이 쉬움 |
| 랜덤 포레스트 | 여러 트리를 결합 |
| SVM(서포트 벡터 머신) | 최대 Margin을 남기는 방향으로 학습 |
| KNN | 가까운 이웃으로 판단 |
| Naive Bayes | 베이즈 확률(조건부 독립을 가정) |
| 신경망 | 복잡한 비선형 패턴 |
| Boosting | 이전 오류를 다음 모델이 보완 |


### 주의할 키워드
- 랜덤 포레스트는 배깅(bagging)을 사용하여 병렬 처리
- 부스팅(boosting)은 순차적으로 모델을 학습(과거의 실수를 보완)
    - AdaBoost
    - Gradient Boosting
    - XGBoost
- KNN : 주변에 고양이가 4, 강아지가 1이면 고양이라고 결정내린다 (유클리드 거리)
- SVM : 클래스간의 거리를 최대로 하는 경계를 찾는 방식
    - 경계와 가장 가까운 데이터가 Support Vector이다
    - 비선형 데이터라면 커널 트릭을 사용하여 차수를 낮춘다

<div style="color:red">
- 로지스틱 회귀는 이름은 회귀지만 분류(classfication)
- 예측이 나온다고 회귀라고 보기는 어렵다
- 의사결정나무는 분류와 회귀 둘다 가능하다 (무조건이란 단어 주의)
- 랜덤 포레스트는 부스팅이 아니다
- 배깅과 부스팅의 목적을 혼동하지 말아야 한다
    - 배깅 - 분산 감소가 목적
    - 부스팅 - 편향 감소에 강점
- 의사 결정 나무에서 Geni지수와 엔트로피는 낮을수록, 정보이득은 클수록 좋다
- KNN의 k가 작다고 좋은게 아니다
- 변수를 추가한다고 R²가 감소하지 않는다 (Adjusted R²은 감소한다)
- 과적합은 분산이 크고, 과소적합은 편향이 크다
</div>







# 비지도 학습

정답이 없는 데이터를 이용한 학습 방법

```
비지도학습
│
├─ 군집분석 Clustering
│   ├─ K-Means
│   ├─ 계층적 군집
│   └─ DBSCAN
│
├─ 차원축소
│   └─ PCA
│
└─ 연관분석
    └─ Apriori
```

가장 중요한것은 `군집 / 차원축소 / 연관분석` 세 가지이다.

### 군집분석 (Clustering)

비슷한 데이터끼리 묶는 것

- K-Means - 데이터를 `k`개의 군집으로 나눠 중심이 거의 이동하지 않을때까지 반복
    - `k`는 엘보우 메소드를 사용하여 K 대비 SSE의 감소폭이 확 줄어드는 지점을 선택
    - 실루엣 계수 : `-1` ~ `1` 사이 범위를 가지며 클 수록 군집이 잘 되어있는것
- DBSCAN - 진짜 DB가 아니라 밀도 기반(Density-Based) 군집화
    - `k`를 지정할 필요가 없으므로 K-Means의 대안이 될 수 있음
    - eps - 거리 범위(한 점 주변에서 어디까지를 이웃으로 볼 것인가)
    - minPts - 밀집지역 판정 기준 개수 (eps 범위 안에 존재하는 데이터 수)
- 계층적 군집 - 데이터를 단계적으로 묶어 dendrogram 등으로 표현
    - 거리 연결 방법 - single, complete, average, ward
        - single은 군집간의 거리를 가장 가까운 거리로 측정
        - complete는 군집간의 거리를 가장 먼 거리로 측정
        - average는 군집간의 거리를 평균 거리로 측정
        - <span style="color:red">ward는 분산 증가를 최소하하는 거리로 측정</span>

### 차원축소 (PCA)

PCA(Principal Component Analysis)는 변수 개수를 줄이는 것이 목적이다.

- PC1 - 데이터를 가장 많이 설명하며, 분산이 최대가 되는 변수

<div style="color:red">
주요 함정
- 중요한 변수를 선택하는것이 아님
- 기존의 변수들을 조합해서 새로운 변수 PC를 생성하는 방향으로 변수 개수를 줄인다
- `(ex)` - PC1 = 0.4 x 키 + 0.5 x 몸무게 + 0.6 x BMI + ...
- 층화와 집락추출은 표본추출방식이지 비지도학습이 다르므로 K-Means랑 구별필요
</div>
