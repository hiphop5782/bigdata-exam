# 비식별화기법

비식별화란 개인정보를 보호하면서 데이터를 활용하기 위해 개인을 식별하기 어렵도록 데이터에 변형을 가하는 작업입니다.

> 가명처리, 총계처리, 데이터 삭제, 범주화, 데이터 마스킹

## 가명처리

개인을 직접 알아볼 수 있는 값을 다른 값으로 대체

> 이름 대신 고객코드를 사용 (홍길동 → CUS102)

## 총계처리

합계, 평균, 빈도 등의 통계정보로 변환

> 300만원, 400만원, 500만원 → 평균 400만원

## 데이터 삭제

식별 가능성이 높은 정보를 원천적으로 제거하는 행위

## 범주화

데이터를 구간이나 범주로 변경

> 37세 → 30대  
> 연봉 4750만원 → 연봉 4000~5000만원  
> 서울 강남구 역삼동 → 서울

## 데이터 마스킹

데이터의 일부분을 `*` 등으로 가려서 식별을 방해

> 피카츄 → 피`*`츄  
> 010-1212-3434 → 010-`****`-3434

## 요약

- 가명 = 바꾼다
- 총계 = 합친다
- 삭제 = 없앤다
- 범주 = 뭉친다
- 마스킹 = 가린다
