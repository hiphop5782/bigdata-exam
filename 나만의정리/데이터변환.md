# 데이터 변환 기법

분석이나 모델링이 잘 되도록 데이터의 크기, 분포, 형태, 의미 등을 바꾸는 작업

## 원본 데이터가 그대로 쓰기 어려운 이유

- 변수마다 단위가 다르거나
- 한쪽으로 심하게 치우쳐 있거나
- 너무 세밀한 값이거나
- 기존 변수만으로는 의미가 부족할 수 있음

## 데이터 변환 기법의 종류

범위를 바꾸는 기법 

1. Scaling - 값의 크기를 맞추는 것
2. Min-Max Scaling - 값의 크기를 `0`~`1`사이로 맞추는 것
3. Z-score 표준화 - 평균 `0`, 표준편차  `1`이 되도록 변환하는 것

분포를 바꾸는 기법  

1. Log Transformation - 큰 값을 압축하는 기법
2. Box-Cox - 로그,제곱근 등 상황에 맞게 적용 <span style="color:red">(양수데이터)</span>
3. Binning - 숫자 데이터를 구간별로 분할하여 범주형 데이터로 변환

새로운 값을 만들어내는 기법

1. 파생변수 - 데이터에서 의미있는 정보를 추출

## 이상치에 민감한 Scaling

Min-Max 변환이나 Z-score 변환은 이상치에 매우 민감하다. 이 경우 중앙값과 IQR을 이용하도록 처리하여 이상치를 제거하는 `Robust scaling`을 사용할 수 있다.

> IQR = Q3 - Q1
