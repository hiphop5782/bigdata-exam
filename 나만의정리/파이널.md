# 1과목: 빅데이터 분석기획

## 빅데이터 특징

- `Volume`: 데이터 규모
- `Velocity`: 생성 및 처리 속도
- `Variety`: 데이터 형태의 다양성
- `Veracity`: 정확성과 신뢰성
- `Value`: 데이터의 가치

## 데이터 유형

| 유형 | 특징 | 예시 |
|---|---|---|
| 정형 | 행과 열로 구조화 | 관계형 데이터베이스 |
| 반정형 | 구조 정보는 있지만 고정 테이블은 아님 | JSON, XML, HTML, 로그 |
| 비정형 | 일정한 구조가 없음 | 이미지, 음성, 영상, 자연어 |

## 데이터 척도

| 척도 | 특징 | 예시 |
|---|---|---|
| 명목 | 구분만 가능 | 성별, 혈액형 |
| 서열 | 순서가 있음 | 만족도, 등급 |
| 등간 | 간격에 의미, 절대적 0 없음 | 섭씨온도 |
| 비율 | 비율에 의미, 절대적 0 존재 | 키, 몸무게, 매출 |

> 암기: 명서등비

- `ETL`: 추출 → 변환 → 적재
- `ELT`: 추출 → 적재 → 변환

# 2과목: 빅데이터 탐색

## 결측값

- `MCAR`: 완전 무작위 결측
- `MAR`: 관측된 다른 변수와 관련된 결측
- `MNAR`: 결측값 자체나 미관측 변수와 관련된 결측
- 처리: 삭제, 평균·중앙값·최빈값 대치, 회귀 대치, KNN 대치, 다중 대치

## 이상값

    IQR = Q3 - Q1
    하한 = Q1 - 1.5 × IQR
    상한 = Q3 + 1.5 × IQR

> 이상값은 중요한 사건일 수 있으므로 무조건 삭제하지 않는다.

## 표준화와 정규화

표준화:

    z = (x - 평균) / 표준편차

- 평균 0, 표준편차 1
- KNN, K-means, SVM, PCA 등에 중요

최소-최대 정규화:

    x' = (x - 최솟값) / (최댓값 - 최솟값)

- 일반적으로 0~1 범위
- 이상값에 민감

## 기술통계

- 평균: 이상값에 민감
- 중앙값: 이상값에 상대적으로 강함
- 최빈값: 범주형에도 사용 가능
- 표본분산의 분모: `n - 1`
- 변동계수: `CV = 표준편차 / 평균`

## 왜도

- 양의 왜도: 오른쪽 꼬리가 김, 일반적으로 평균 > 중앙값 > 최빈값
- 음의 왜도: 왼쪽 꼬리가 김, 일반적으로 평균 < 중앙값 < 최빈값

## 확률

    P(A|B) = P(A∩B) / P(B)
    독립이면 P(A∩B) = P(A)P(B)
    P(A|B) = P(B|A)P(A) / P(B)

> 독립사건과 배반사건은 다르다.

## 주요 확률분포

| 분포 | 용도 |
|---|---|
| 베르누이 | 한 번의 성공과 실패 |
| 이항 | 반복 시행의 성공 횟수 |
| 포아송 | 일정 시간·공간의 사건 발생 횟수 |
| 정규 | 평균 중심의 대칭 연속분포 |
| 지수 | 사건 사이의 대기시간 |
| t | 모분산을 모르는 소표본 평균 추론 |
| 카이제곱 | 분산·독립성·적합도 검정 |
| F | 분산의 비와 분산분석 |

이항분포:

    E(X) = np
    Var(X) = np(1-p)

포아송분포:

    E(X) = Var(X) = λ

## 중심극한정리

- 표본 크기가 충분히 크면 표본평균의 분포가 정규분포에 가까워진다.
- 모집단 자체가 정규분포가 된다는 뜻은 아니다.

    SE = σ / √n

> 표본 수가 4배가 되면 표준오차는 절반이 된다.

## 가설검정

- `H₀`: 차이나 효과가 없음
- `H₁`: 차이나 효과가 있음
- `p-value < α`: 귀무가설 기각
- `p-value ≥ α`: 귀무가설을 기각하지 못함
- 1종 오류: 참인 귀무가설을 기각
- 2종 오류: 거짓인 귀무가설을 기각하지 못함
- 검정력: `1 - β`

> p-value는 귀무가설이 참일 확률이 아니다.

## 검정 선택

| 상황 | 검정 |
|---|---|
| 한 집단 평균과 기준값 비교 | 일표본 t검정 |
| 같은 대상의 전후 평균 비교 | 대응표본 t검정 |
| 독립된 두 집단 평균 비교 | 독립표본 t검정 |
| 세 집단 이상 평균 비교 | ANOVA |
| 범주형 변수 간 관계 | 카이제곱 독립성 검정 |
| 두 연속변수의 선형 관계 | Pearson 상관분석 |
| 정규성 검정 | Shapiro-Wilk |

비모수 검정:

| 상황 | 검정 |
|---|---|
| 독립된 두 집단 | Mann-Whitney U |
| 대응된 두 집단 | Wilcoxon signed-rank |
| 세 집단 이상 | Kruskal-Wallis |
| 순위 상관 | Spearman |

## ANOVA

- 귀무가설: 모든 집단의 평균이 같다.
- 유의하면 적어도 한 집단의 평균이 다르다.
- 어느 집단이 다른지는 사후검정이 필요하다.

    F = 집단 간 분산 / 집단 내 분산

## 상관계수

    r = Cov(X,Y) / (sₓsᵧ)

- 범위: -1~1
- 0에 가까우면 선형관계가 약함
- 비선형관계가 강해도 0에 가까울 수 있음
- 상관관계는 인과관계를 의미하지 않음

# 3과목: 빅데이터 모델링

## 학습 유형

- 지도학습: 정답 `y`가 있음
  - 분류: 범주 예측
  - 회귀: 연속값 예측
- 비지도학습: 정답이 없음
  - 군집, 연관분석, 차원축소
- 강화학습: 누적 보상을 최대화하는 정책 학습

## 선형회귀

    y = β₀ + β₁x + ε
    R² = 1 - SSE / SST

회귀 가정:

- 선형성
- 오차의 독립성
- 등분산성
- 오차의 정규성
- 심각한 다중공선성이 없음

## 다중공선성

- 독립변수 사이에 강한 선형관계가 있는 현상
- 계수가 불안정하고 표준오차가 증가함
- VIF가 클수록 의심
- 변수 제거·결합, PCA, Ridge, Lasso 등으로 대응

## Ridge와 Lasso

Ridge:

    손실 = SSE + λΣβⱼ²

- L2 규제
- 계수를 0에 가깝게 축소

Lasso:

    손실 = SSE + λΣ|βⱼ|

- L1 규제
- 일부 계수를 0으로 만들어 변수 선택 가능

## 로지스틱 회귀

    p = 1 / (1 + e⁻ᶻ)
    log(p / (1-p)) = β₀ + β₁x₁ + ...

- 분류 모델
- `p/(1-p)`는 오즈
- 계수만큼 변수가 증가하면 오즈는 `e^β`배

## 의사결정나무

- 해석이 쉽고 비선형 관계를 처리함
- 변수 스케일 영향이 작음
- 과적합과 데이터 변화에 민감함

    Gini = 1 - Σpₖ²
    Entropy = -Σpₖlog₂pₖ
    정보이득 = 분할 전 불순도 - 분할 후 가중 불순도

> 노드가 순수할수록 불순도가 작다.

## 앙상블

- Bagging: 부트스트랩 표본, 병렬 학습, 분산 감소
- Random Forest: 배깅 + 분할마다 일부 변수 무작위 선택
- Boosting: 이전 모델의 오류를 다음 모델이 순차적으로 보완
- AdaBoost: 오분류 데이터 가중치 증가
- Gradient Boosting: 손실의 음의 그래디언트 학습

## KNN

- 가까운 K개 이웃으로 예측
- 거리 기반이므로 스케일링 중요
- K가 너무 작으면 과적합, 너무 크면 과소적합 가능

## SVM

- 클래스 사이의 마진을 최대화
- 서포트 벡터가 결정경계를 결정
- 커널을 이용해 비선형 분류 가능
- 스케일링 중요
- `C`가 크면 오분류를 강하게 벌해 과적합 가능
- `gamma`가 크면 결정경계가 복잡해질 수 있음

## K-means

1. K개 중심 초기화
2. 가장 가까운 중심에 데이터 할당
3. 군집 평균으로 중심 갱신
4. 수렴할 때까지 반복

- K를 미리 지정
- 스케일링 중요
- 이상값과 초기 중심에 민감
- 구형 군집에 적합

실루엣 계수:

- 1에 가까움: 군집 분리 우수
- 0 근처: 경계
- 음수: 잘못 배정되었을 가능성

## DBSCAN

- 밀도 기반 군집
- 군집 수를 미리 지정할 필요 없음
- 임의 모양 군집과 노이즈 탐지 가능
- 주요 파라미터: `epsilon`, `MinPts`

## PCA

- 변수들의 선형결합으로 주성분 생성
- 첫 번째 주성분이 가장 큰 분산을 설명
- 주성분끼리 직교
- 비지도학습
- 변수 스케일이 다르면 표준화 필요
- 종속변수를 고려하지 않음

## 연관분석

    Support(A → B) = P(A∩B)
    Confidence(A → B) = P(B|A) = P(A∩B) / P(A)
    Lift(A → B) = P(B|A) / P(B)

- `Lift > 1`: 양의 연관
- `Lift = 1`: 독립
- `Lift < 1`: 음의 연관

## 시계열

- 구성요소: 추세, 계절성, 순환, 불규칙성
- 정상성: 평균과 분산이 일정하고 공분산이 시차에만 의존
- 차분: 추세 제거 및 정상성 확보에 사용

    ARIMA(p, d, q)

- `p`: AR 차수
- `d`: 차분 횟수
- `q`: MA 차수
- ACF: MA 차수 판단에 주로 참고
- PACF: AR 차수 판단에 주로 참고

## 텍스트 분석

- 토큰화, 정제, 불용어 제거, 어간·표제어 추출
- TF: 문서 내 단어 빈도
- IDF: 여러 문서에 흔한 단어일수록 낮은 가중치
- TF-IDF: 특정 문서에 많고 전체 문서에는 드문 단어의 가중치가 큼

## 신경망

- Sigmoid: 0~1
- Tanh: -1~1
- ReLU: `max(0, x)`
- Softmax: 다중 클래스 확률의 합이 1
- 순전파 → 손실 계산 → 역전파 → 가중치 갱신
- 과적합 방지: Dropout, 규제, 조기 종료, 데이터 증강
- CNN: 이미지
- RNN·LSTM·GRU: 순서 및 시계열
- Transformer: Attention 기반

# 4과목: 빅데이터 결과 해석

## 과적합과 과소적합

- 과적합: 훈련 성능은 높지만 새로운 데이터 성능은 낮음
- 과소적합: 모델이 너무 단순하여 훈련·평가 성능 모두 낮음

## 데이터 분할

- Train: 모델 학습
- Validation: 모델과 하이퍼파라미터 선택
- Test: 최종 일반화 성능 평가

> 테스트 데이터는 최종 평가에만 사용한다.

## 교차검증

- K-fold: 데이터를 K개로 나누어 검증 대상을 바꾸며 K번 학습
- Stratified K-fold: 각 폴드의 클래스 비율 유지
- 시계열 데이터: 시간 순서를 유지하고 미래 정보 사용 금지

## 데이터 누수

- 전체 데이터로 표준화한 뒤 분할
- 테스트 데이터로 변수 선택
- 미래 정보를 설명변수로 사용
- 전체 데이터의 평균으로 결측값 대치

> 전처리 기준도 훈련 데이터에서만 학습한다.

## 혼동행렬

| 구분 | 실제 양성 | 실제 음성 |
|---|---:|---:|
| 예측 양성 | TP | FP |
| 예측 음성 | FN | TN |

    Accuracy = (TP + TN) / (TP + TN + FP + FN)
    Precision = TP / (TP + FP)
    Recall = TP / (TP + FN)
    Specificity = TN / (TN + FP)
    F1 = 2 × Precision × Recall / (Precision + Recall)

- 정밀도 분모: 예측 양성
- 재현율 분모: 실제 양성
- 환자를 놓치면 위험: 재현율 중요
- 정상 대상을 양성 처리하면 위험: 정밀도 중요
- 불균형 데이터에서는 정확도만 보면 위험

## ROC와 AUC

- ROC X축: `FPR = FP / (FP + TN)`
- ROC Y축: `TPR = Recall`
- AUC가 1에 가까울수록 좋음
- 0.5는 무작위 분류 수준
- 불균형이 심하면 PR-AUC가 더 유용할 수 있음

임계값을 낮추면 일반적으로:

- 양성 예측 증가
- 재현율 증가
- 위양성 증가
- 정밀도 감소 가능

## 회귀 평가 지표

    MAE = Σ|yᵢ - ŷᵢ| / n
    MSE = Σ(yᵢ - ŷᵢ)² / n
    RMSE = √MSE
    MAPE = (100/n) × Σ|(yᵢ - ŷᵢ) / yᵢ|

- MAE: 이상값 영향이 MSE보다 작음
- MSE: 큰 오차에 강한 벌점
- RMSE: 종속변수와 같은 단위
- MAPE: 실제값이 0 또는 0에 가까우면 문제

낮을수록 좋은 지표:

- MAE, MSE, RMSE, MAPE, Log Loss

높을수록 좋은 지표:

- Accuracy, Precision, Recall, F1, AUC, R²

## 편향과 분산

- 높은 편향: 과소적합
- 높은 분산: 과적합

| 문제 | 대응 |
|---|---|
| 높은 편향 | 모델 복잡도 증가, 변수 추가, 규제 완화 |
| 높은 분산 | 데이터 추가, 모델 단순화, 규제 강화, 배깅 |

## 모델 해석

- 트리 중요도: 분할 과정에서의 기여도
- 순열 중요도: 변수를 섞었을 때 성능 감소 측정
- SHAP: 각 변수가 개별 예측에 기여한 방향과 크기 설명
- PDP: 변수 변화에 따른 평균 예측값 변화 표시

## 통계적 유의성과 실무적 중요성

- 통계적으로 유의하다고 실무적으로 중요한 것은 아님
- 표본이 매우 크면 작은 차이도 유의할 수 있음
- p-value와 함께 효과크기와 신뢰구간 확인
- 신뢰구간이 좁을수록 일반적으로 추정이 정밀함

# 시험 직전 필수 암기 30개

1. 필기는 총점 60점 이상, 과목별 40점 이상이어야 한다.
2. 과목별 최소 8문항, 전체 최소 48문항을 맞혀야 한다.
3. CRISP-DM은 업무 → 데이터 → 준비 → 모델 → 평가 → 전개이다.
4. ETL은 적재 전 변환, ELT는 적재 후 변환이다.
5. 층화추출은 모든 층에서 표본을 뽑는다.
6. 군집추출은 일부 군집을 선택한다.
7. CAP는 일관성·가용성·분할 내성이다.
8. HDFS는 저장, MapReduce는 처리, YARN은 자원관리이다.
9. 평균은 이상값에 민감하고 중앙값은 상대적으로 강하다.
10. 표본분산의 분모는 `n-1`이다.
11. 양의 왜도는 오른쪽 꼬리가 길다.
12. 독립사건과 배반사건은 다르다.
13. `p-value < α`이면 귀무가설을 기각한다.
14. 1종 오류는 참인 귀무가설을 기각하는 오류이다.
15. 검정력은 `1-β`이다.
16. 세 집단 이상의 평균 비교는 ANOVA이다.
17. 범주형 변수 간 관계는 카이제곱 독립성 검정이다.
18. 상관관계는 인과관계를 의미하지 않는다.
19. Ridge는 L2 규제이다.
20. Lasso는 L1 규제이며 변수 선택이 가능하다.
21. Random Forest는 Bagging 기반이다.
22. Boosting은 이전 모델의 오류를 순차적으로 보완한다.
23. KNN·SVM·K-means는 스케일링이 중요하다.
24. PCA는 비지도학습이며 분산을 최대한 보존한다.
25. 지지도는 교집합, 신뢰도는 조건부확률이다.
26. 향상도가 1이면 두 항목은 독립이다.
27. ARIMA의 `p`, `d`, `q`는 AR·차분·MA이다.
28. 정밀도의 분모는 예측 양성, 재현율의 분모는 실제 양성이다.
29. MSE는 MAE보다 큰 오차에 민감하다.
30. 통계적 유의성과 실무적 중요성은 다르다.
