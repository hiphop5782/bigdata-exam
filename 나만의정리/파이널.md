# 1과목: 빅데이터 분석기획

## 1. 빅데이터 특징

### 3V

- `Volume`: 데이터 규모
- `Velocity`: 생성 및 처리 속도
- `Variety`: 데이터 형태의 다양성

### 확장된 특징

- `Veracity`: 정확성과 신뢰성
- `Value`: 데이터의 가치

## 2. 데이터 유형

| 유형 | 특징 | 예시 |
|---|---|---|
| 정형 | 행과 열로 구조화 | 관계형 데이터베이스 |
| 반정형 | 구조 정보는 있지만 고정 테이블은 아님 | JSON, XML, HTML, 로그 |
| 비정형 | 일정한 구조가 없음 | 이미지, 음성, 영상, 자연어 |

## 3. 데이터 척도

| 척도 | 특징 | 예시 |
|---|---|---|
| 명목척도 | 구분만 가능 | 성별, 혈액형 |
| 서열척도 | 순서가 있음 | 만족도, 등급 |
| 등간척도 | 간격에 의미, 절대적 0 없음 | 섭씨온도 |
| 비율척도 | 간격과 비율에 의미, 절대적 0 존재 | 키, 몸무게, 매출 |

> 암기: 명서등비

## 4. 분석 방법론

### KDD

1. 데이터 선택
2. 데이터 전처리
3. 데이터 변환
4. 데이터 마이닝
5. 결과 해석 및 평가

### CRISP-DM

1. 업무 이해
2. 데이터 이해
3. 데이터 준비
4. 모델링
5. 평가
6. 전개

> 암기: 업무 → 데이터 → 준비 → 모델 → 평가 → 전개

### SEMMA

1. `Sample`: 표본 추출
2. `Explore`: 탐색
3. `Modify`: 수정 및 변환
4. `Model`: 모델링
5. `Assess`: 평가

## 5. 분석 접근법

- 하향식 접근: 업무 문제를 먼저 정의하고 데이터를 분석
- 상향식 접근: 데이터에서 패턴을 발견하여 문제나 가설 도출
- 디자인 사고: 발산과 수렴을 반복하며 문제 해결

## 6. 분석 과제 유형

| 목적 | 방법 | 유형 |
|---|---|---|
| 명확 | 명확 | 최적화 |
| 명확 | 불명확 | 솔루션 |
| 불명확 | 명확 | 통찰 |
| 불명확 | 불명확 | 발견 |

## 7. 데이터 수집

### 조사 방법

- 전수조사: 모집단 전체를 조사
- 표본조사: 모집단 일부로 전체 특성을 추론

### 표본추출 방법

- 단순무작위추출: 모든 대상이 같은 확률로 선택
- 계통추출: 일정한 간격으로 선택
- 층화추출: 동질적인 층으로 나눈 뒤 모든 층에서 추출
- 군집추출: 모집단과 유사한 군집을 만들고 일부 군집 선택

> 층화추출은 모든 층에서 표본을 뽑고, 군집추출은 일부 군집을 선택한다.

### 수집 기술

- 크롤링: 웹페이지를 자동으로 탐색하여 데이터 수집
- 스크래핑: 웹페이지에서 필요한 정보 추출
- Open API: 표준 인터페이스를 통한 데이터 요청
- 로그 수집: 시스템이나 사용자 활동 기록 수집
- IoT: 센서를 통한 실시간 데이터 수집

## 8. ETL과 ELT

- `ETL`: 추출 → 변환 → 적재
- `ELT`: 추출 → 적재 → 변환

## 9. 관계형 DB와 NoSQL

### 관계형 DB

- 테이블 구조
- SQL 사용
- 스키마가 명확함
- 정규화를 통해 중복과 이상현상 감소

### NoSQL 유형

| 유형 | 예시 |
|---|---|
| Key-Value | Redis |
| Document | MongoDB |
| Column Family | HBase, Cassandra |
| Graph | Neo4j |

### NoSQL 특징

- 유연한 스키마
- 수평 확장이 쉬움
- 대용량·분산·비정형 데이터 처리에 적합

## 10. ACID와 BASE

### ACID

- `Atomicity`: 원자성
- `Consistency`: 일관성
- `Isolation`: 격리성
- `Durability`: 지속성

### BASE

- `Basically Available`: 기본적 가용성
- `Soft State`: 소프트 상태
- `Eventually Consistent`: 최종적 일관성

## 11. CAP 정리

- `Consistency`: 일관성
- `Availability`: 가용성
- `Partition Tolerance`: 분할 내성

> 네트워크 분할이 발생하면 일반적으로 일관성과 가용성을 동시에 완벽하게 보장하기 어렵다.

## 12. Hadoop과 Spark

### Hadoop

- `HDFS`: 분산 파일 저장
- `NameNode`: 파일 및 블록의 메타데이터 관리
- `DataNode`: 실제 데이터 블록 저장
- `MapReduce`: 분산 병렬 처리
- `YARN`: 자원과 작업 관리

### MapReduce 과정

1. `Map`: 데이터를 키-값 형태로 변환
2. `Shuffle/Sort`: 같은 키끼리 정렬 및 그룹화
3. `Reduce`: 집계하여 결과 생성

### Spark

- 인메모리 처리 중심
- 반복 연산과 머신러닝에 유리
- `RDD`: 장애 복구가 가능한 분산 데이터 집합

## 13. 개인정보

- 개인정보: 개인을 식별할 수 있는 정보
- 가명정보: 추가 정보 없이는 개인 식별이 어려운 정보
- 익명정보: 개인을 식별할 수 없고 복원이 사실상 불가능한 정보

### 비식별 처리

- 가명처리
- 총계처리
- 데이터 삭제
- 데이터 범주화
- 데이터 마스킹

## 14. 정보보안 3요소

- 기밀성: 허가된 사용자만 접근
- 무결성: 데이터가 임의로 변경되지 않음
- 가용성: 필요할 때 정상적으로 사용 가능

> 암기: 기무가

# 2과목: 빅데이터 탐색

## 1. 데이터 품질

- 정확성
- 완전성
- 일관성
- 유효성
- 적시성
- 유일성

## 2. 결측값

### 결측 메커니즘

- `MCAR`: 완전 무작위 결측
- `MAR`: 관측된 다른 변수와 관련된 결측
- `MNAR`: 결측값 자체 또는 관측되지 않은 변수와 관련된 결측

### 처리 방법

- 행 또는 열 삭제
- 평균·중앙값·최빈값 대치
- 회귀 대치
- KNN 대치
- 다중 대치

> 이상값이 있거나 분포가 치우친 수치형 변수는 평균보다 중앙값 대치가 안전하다.
