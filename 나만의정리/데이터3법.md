# 데이터3법 (개인정보보호3법)

2020년에 개정된 다음 3개 법률을 묶어서 부르는 표현

- 개인정보 보호법
- 정보통신망법
- 신용정보법

# 데이터 3법의 목적

개인정보는 보호하되, 가명처리등을 통해 데이터는 분석, 연구, 산업에 활용할 수 있도록 하자

# 개인정보 보호법

1. 가명정보의 개념 도입
2. 가명정보는 일정 목적에서 동의 없이 이용 가능
3. 개인정보 보호체계 일원화

## 개인정보 보호법의 중요포인트

- 통계작성, 과학적 연구, 공익적 기록보존 목적이면 일정 요건하에 동의 없이 데이터 활용 가능
- 개인정보 보호 감독기능을 개인정보 보호위원회 중심으로 정비

## 개인정보 보호위원회

국무총리 소속의 독립적인 합의제 중앙행정기관  
기존 여러 기관에 분산된 감독기능을 법 개정으로 통합

> 자주 나오는 오답 지문
> - 행정안전부 소속이다 (x)
> - 단순 자문기관이며 법적 구속력이 없다 (x)
> - 정책 수립권한은 있지만 조사권한이 없다 (x)


# 정보통신망법

정식 명칭은 `정보통신망 이용촉진 및 정보보호 등에 관한 법률`이다.

기존에는 온라인 사업자가 개인정보를 가지고 있을 경우에 대한 내용이 정보통신망법에 있었으나 이 부분을 2020년 데이터3법 개정에서 개인정보보호법으로 이관하였다.

정보통신망법은 계속해서 정보통신망 자체의 보안에 대해서 다루는 역할을 수행하고 있다.

- 정보통신망의 안정성
- 침해사고 대응
- 정보보호
- 불법정보 유통
- 정보보호시스템

> 데이터3법 개정으로 정보통신망법이 폐지되고 개인정보보호법으로 흡수되었다(x)

# 신용정보법

금융과 관련된 개인정보는 보호하면서 연구목적으로 활용할 수 있도록 관리하기 위한 법

- 데이터 전문기관을 이용한 서로 다른 금융기관의 데이터 결합 가능
- 마이데이터를 이용한 금융 종합 서비스 가능


> 데이터 전문기관 (2026 기준)  
> - 한국신용정보원, 금융보안원, 금융결제원, 국세청, 국가데이터처(전 통계청)
> - 비씨카드, 삼성카드, 신한카드, 신한은행, 삼성SDS, 쿠콘
