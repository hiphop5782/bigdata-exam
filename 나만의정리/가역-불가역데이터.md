# 가역데이터와 불가역데이터

데이터를 활용해서 정보를 만들어내는 과정에서 데이터를 복원 가능 여부에 따라 가역데이터와 불가역 데이터로 만들 수 있다.

- 가역데이터 : 원래 데이터로 복원이 가능한 데이터
- 불가역데이터 : 원래 데이터로 복원이 불가능한 데이터

## 가역 데이터

원래 데이터로 복원 가능한 데이터

> 서울 강남구 역삼동 → LOC_015

별도의 복원을 위한 매핑테이블을 가지고 있으며 원한다면 언제든 복원 가능

## 불가역 데이터

> 30세, 35세, 37세 → 30대

데이터의 손상이 가해지기 때문에 원래 형태로 복원할 수 없음. 가장 대표적인 알고리즘이 해시(Hash) 알고리즘이다.
