# 혼동 행렬

혼동 행렬은 분류 모델의 성능을 평가하는 도구.

## 구분

- TP : 실제 양성을 양성으로 잘 맞춤
- TN : 실제 음성을 음성으로 잘 맞춤
- FP : 실제 음성인데 양성으로 틀림 (1종 오류)
- FN : 실제 양성인데 음성으로 틀림 (2종 오류)

## 주요 평가 지표

- 정확도(Accuracy) : 전체 경우 중 맞춘 비율 (전체에서 TP, TN의 비율)
- 정밀도(Precision) : 양성으로 예측한 것 중 실제 양성 비율 (TP+FP 중에서 TP의 비율)
- 재현율(Recall/Sensitivity) : 실제 양성 중 모델이 맞춘 비율(TP+FN 중에서 TP의 비율)
- F1-Score : 정밀도와 재현율의 조화 평균
- 민감도=재현율
- 특이도 : 실제 음성 중 모델이 맞춘 비율(TN+FP 중에서 TN의 비율)

```
특이도 = 1 - 1종 오류
```

```
민감도 = 1 - 2종 오류
```

이들을 이용해서 ROC 곡선을 그림
