# 결정계수 (R²)

회귀 모델이 종속 변수의 전체 변동성 중 몇 %를 설명하는지 나타내는 수치

범위 : `0 ≤ R² ≤ 1`

# 계산 공식과 용어

```
R² = SSR / SST = 1 - SSE / SST
```

| 용어 | 의미 | 설명 | 
| SST (Total) | 전체 제곱합 | 실제값과 평균값 차이의 제곱합 (데이터의 전체 변동성) | 
| SSR (Regression) | 회귀 제곱합 | 예측값과 평균값 차이의 제곱합 (모델이 설명한 변동성) | 
| SSE (Error) | 잔차 제곱합 | 실제값과 예측값 차이의 제곱합 (모델이 설명 못한 오차) |

# 수정된 결정계수

일반 결정계수의 치명적인 문제인  **독립 변수 추가 시 무조건 올라가는 경향** 때문에 이를 보완하기 위해 변수의 개수와 샘플 수를 고려하여 계산하도록 처리

$$
R^2_{adj} = 1 - \frac{(1 - R^2)(n - 1)}{n - p - 1}
$$
